第3章 ArkTS语言编程基础

3.1.1 基本数据类型

ArkTS的基本数据类型有3种：number、boolean、string


// 声明局部变量，必须加 let，如果不赋初始值必须显式标注变量数据类型
let a:number = 1;
let bool:boolean = true;
let str:string = '你好';

3.1.2 数组类型

ArkTS中有两种数组写法：T[] 和 Array<T>


// 声明数组
let a : number[] = [1,2,3]
let b : Array<number> = [1,2,3]
let c = ['A','B','C']

3.1.3 类及对象

ArkTS支持使用interface关键字来定义具体的接口结构


// interface 内部只能定义属性，不能定义方法
interface UserInterface {
    name: string
    isMale: boolean
    age: number
}

// 接口变量的声明必须指定数据类型
// 修改时必须对所有字段重新赋值
let xiaoming: UserInterface = { name: '小明', isMale: true, age: 20 }

ArkTS支持使用class关键字来定义具体的类结构


// class内部既能定义属性，又能定义方法
class UserClass {
    name: string
    isMale: boolean = true
    age: number

    // 不允许出现未初始化属性字段
    constructor() {
        this.name = ''
        this.age = 0
    }
}

let xiaohong : UserClass = new UserClass()
xiaohong.name = '小红'
xiaohong.isMale = false
xiaohong.age = 18
